# GitHub Publishing Checklist

Use this checklist when preparing a public copy of BirthdayFlix.

## Suggested repository description

> A customizable Netflix-inspired birthday website template with interactive carousels, hover previews, profile selection, and personalized messages. Add your own photos, videos, and memories.

## Suggested GitHub Topics

Add these from **Repository → About → Topics** (choose the ones that best describe your version):

- `birthday-website`
- `birthday-template`
- `html-css-javascript`
- `static-website`
- `photo-gallery`
- `interactive-ui`
- `netflix-inspired`
- `customizable-template`

## Repository settings

- [ ] Confirm the repository contains no private photos, videos, messages, or live credentials.
- [ ] Add a license only after deciding what reuse permissions you want to grant.
- [ ] Consider enabling **Template repository** in **Settings → General** so visitors can create their own copies.
- [ ] Set a clear repository description and add relevant topics.
- [ ] Upload `docs/social-preview.png` as the social preview in **Settings → General → Social preview**.
- [ ] Check README links, placeholder filenames, demo login, carousel count, and mobile layout.
- [ ] Review external assets, favicon service, and brand references before sharing publicly.

## Optional publishing targets

The project is a static site and can be served locally or hosted on any compatible static hosting service. If deploying on Vercel, the included `vercel.json` redirects `/` to `loginPage.html`. For a different host, test its root route and remove or adapt `vercel.json` as needed.

## First release checklist

- [ ] Write a clear first release note.
- [ ] Explain that default credentials and PIN are demo-only.
- [ ] Include a screenshot/GIF of the site with placeholders.
- [ ] Invite helpful bug reports and small pull requests.
- [ ] Do not ask for stars in exchange for support; focus on making the template useful.
