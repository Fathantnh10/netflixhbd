# Security Notes

BirthdayFlix is a static front-end demo. Login credentials and the profile PIN are defined in `customization.js` and can be inspected or bypassed by anyone who can load the site. Do not use real credentials or depend on the PIN to protect confidential media.

If you find a problem that could expose private information in a deployed customized site, do not post personal media or secrets in a public issue. Contact the site owner privately.
