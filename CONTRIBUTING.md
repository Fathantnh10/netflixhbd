# Contributing

Thanks for helping improve BirthdayFlix!

## Before opening an issue or pull request

- Search existing issues to avoid duplicates.
- Describe the page and browser where you observed a problem.
- Do not include private photos, passwords, PINs, or personal messages in public issues.
- Keep changes focused and preserve the no-build-step workflow where possible.

## Local test

1. Start a local server with `python -m http.server 8000`.
2. Open `http://localhost:8000/loginPage.html`.
3. Test sign-in, both profiles, demo PIN, hero playback, carousel arrows, hover previews, and the More Info modal.
4. Check at least one desktop and one narrow/mobile viewport.

## Pull requests

- Explain the user-facing change and why it helps.
- List the pages and interactions you tested.
- Avoid adding third-party photos, videos, fonts, audio, or logos unless the license permits redistribution.
- Do not introduce real credentials or private user data.
